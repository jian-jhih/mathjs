# 萬以下加減法

本單元 proposal：[four_digit_money_blocks_proposal.md](four_digit_money_blocks_proposal.md)

核心先使用 1000、100、10、1 四種位值積木，完成位值、進位與退位後，再把 500、50、5 加入生活面值延伸。最後整合線段／開放數線與直式算法。

新版 Proposal 增加 `1702 + 905` 的逐片操作示範：學生先分別看見兩組積木，再一次加入或拖曳 100 積木，觀察 10 個百交換成 1 個千，並可延伸為「積木飛機」任務。詳見 [four_digit_money_blocks_proposal.md](four_digit_money_blocks_proposal.md) 的「直覺操作原則」與「積木飛機任務」。

目前單檔教具實作於 [four_digit_addition_subtraction_app.html](four_digit_addition_subtraction_app.html)，固定示範 `1702 + 905`。教學／練習模式以逐片加入與手動交換為主，積木飛機挑戰逐片發射 905 的積木；位值積木、開放數線 `1702 → 2602 → 2607` 與保留十位 0 的直式 `1702 + 0905` 同步呈現。完成百位交換、送出 9 個百與 5 個一後，可按檢查過關。
